Introduction

The no-three-in-line problem is a geometric arrange problem. Let for every natural number n a n×n Cartesian grid be given in the Euclidean plane. The problem/task is now to select for each number n 2n-many of the intersection points of the n2 grid points under the condition that no three of these 2n points lie in a straight line. One can obviously choose (or select) at most 2n points of the n2-many grid points.

Firstly only for the grid size 8×8 H.E. Dudeney published the problem 1906 in the Indian daily newspaper "The Tribune". Latest 1914, this was cited and published again in the book "Mathematical Recreations and Essays" by Rouse Ball.
The problem of finding for which general grid sizes n×n the upper bound 2n is reached is known as the no-three-in-line problem, introduced at latest 1951.

A closely related question is: How many points can maximally be selected/placed under this restriction? P. Erdös has shown that (1-eps)n points can be placed in a given n×n grid for all sufficient large n. Hall, Jackson, Sudbery, and Wild made the substantial improvement to (3/2-eps)n in 1975. This is the best known asymptotic lower bound. But Guy and Kelly used a probabilitic argument to support their conjecture that for large grids the limit does not reach 2n -- the main conjecture.

State of the Art 1997

Better you have a look to both, old and new, data as a collection of many files or as a list of coded configurations (1.6MB). To decypher this code use this C-program. For those who haven't access to a C-compiler: Each line represents a configuration and each character in it denotes a chosen column position, except the first one, which indicates the symmetry class. The positions are coded from left to right and from top to bottom in each configuration. They are indicated by the alphabet 0,1,2,...,9,A,B,C...,Z,a,b,...,z only in their column positions.

About the implemented Algorithm

My program nothree needs about 4 n^4 + O(n^2) bytes storage and was first implemented in July 1988. Its last release was of November 1991 and consists of about 600 lines of C sourcecode.

A new version was just in April 1996 implemented. Aside the fact that computers nowadays seem to be by a factor 15-20 quicker, the refined algorithm itself gives a speedup of 1.5 - 8 depending on the examined symmetry class. It is very important to traverse the tree of the possible configurations in a proper chosen order. And this depends stronly of the symmetry class.
Furthermore with a simple trick, the restriction of n ≤ 64 (due to the internal data structure) could be risen to n ≤ 90 without any runtime or memory increase. Currently I can check n = 72 for configurations with full symmetry in the same cputime as those for n = 60 with the old algorithm used 1991.
The algorithm independent of symmetries of the grid and the current one for full symmetry of the grid are downloadable for free.

Since 7th June 1996 a new format for the coded configurations is in use: Now each configuration is lead in by a symmetry-class character of the list (. : / - o c x + *) which indicates the symmetry (iden rot2 dia1 ort1 rot4 rct4 dia2 ort2 full) respectively. Further, the selected positions are indicated by the alphabet 0,1,2,...,9,A,B,C...,Z,a,b,...,z only in their column positions from top to bottom row and in every row from left to right. A coded configuration must be terminated by a newline or space or tab.
In February 2026 the first configuration with n=62 was discovered which triggered the extension of the alphabet by 28 more characters. Thus the alphabet for encoding is now "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz#$%&@?!()[]<>{}=*+|-/~^_:;,.". It consists of 90 characters and contains all ASCII-characters > 32 and < 127 except 4 unused characters. For examples of configuration encodings simply look at some configurations you may choose in the following section.

Conjectures

Main Conjecture (≤ 1967)
There are only finite many different no-three-in-line configurations. I.e. there is a (smallest) grid size n such that no configurations satisfying the no-three-in-line condition exist for any size greater this n.
If n tends to infinity, there are only (2/3PI2)(1/3)n = 1.873... n points selectable such that any three of them do not lie in a straight line.
In March 2004 Gabor Ellmann, a hungarian amateur mathematician, discovered an error in Guy & Kellys published derivation of 1968.
If this "substitution"-mistake is corrected it results: asymptotically are only PI/31/2 n = 1.814... n points selectable.
Conjecture I (R.K. Guy & P.A. Kelly 1968)
There are exactly 3 configurations having the full symmetry of the grid.
Conjecture II (R.K. Guy & P.A. Kelly 1968)
Each configuration having ort2 symmetry has the full symmetry of the grid.
Conjecture III (renewed 2026)
There are exactly 7 no-three-in-line configurations having reflection symmetry in a mid-perpendicular.
Conjecture IV (reformulated 2026)
There are exactly 35 no-three-in-line configurations having reflection symmetry in both long diagonals.

The former Conjecture III was disproved in June 1996 by the discovery of a further, 6th, no-three-in-line configuration having reflection symmetry.

A Superficial Explanation

To understand the relative number of solutions in the classes ort1, rot2, dia1 or the classes ort2, rot4, dia2 notice that in the orthogonal symmetry class ort1, resp. ort2, two independent selected points force typically the blockade of n points for 2 of 6, respectively for 8 of 28, straight lines together with their 2, resp. 6, symmetry points. For the diagonal reflection classes dia1 and dia2 two independent selected points force typically the blockade of n/2 points ... . And in the rotation symmetry classes rot? two independent selected points force typically the blockade of about C log(n). The effect of blockade of the remainding 4 of 6, respectively 20 of 28, straight lines seem roughly independent of the regarded symmetry class.

Therefore one should expect most different configurations for given n in the rotational symmetry classes but least different configurations in those with mid-perpendicular symmetry. For a precise analysis of the asymmetric case, see the paper of Guy and Kelly 1968. Their idea can be applied to a special symmetry class to get probabilistic estimations for the number of different configurations. The relation of the numbers for different symmetry class but fixed n should be at least the same as the counted ones for the generatable configurations.

Sub No-3-in-line Solutions

Due to a correspondence from John Selfridge, I checked the collected configurations whether they contain a no-3-in-line solution for smaller n than the given one. Besides the 3 known "diagonal extentions" for o2423670617014535 , :3458148A130A7902692567 , :372845190A460A19562837 the only subsolutions I found is the 2x2 solution. Almost all of these configurations belongs to symmetry class rot2 or rot4. Only 5 examples for n=12, 13, 14, are assymmetric and one with n=15 has reflection symmetry at its long diagonal. But there are more assymmetric for n >= 15. Those configurations having 2x2 blocks in class rot4 have the only block at their center, except the 2 configurations o2323676701014545 and o9OGHGHAM6M06OP34BFBTEQKL12128JALRSRS893F0IEIPQ45NT7N7JCDCD5K. There are centerblock configurations in this symmetry class for n=2,10,14,22,28,30,32,...,42,44 and probably for more n >= 46.

Corrections to published Data

In the 1992 published enumeration table in JCT wrong numbers were given in column o for n >= 30. A program bug causes some missed solutions in symmetry class rot4, which were discovered now by a recomputation. The correct numbers are 92 instead of 62 for n = 30 and 101 in place of 99 for n = 32.
Due to my unconcentration the value for n=20 in column : is a miscount. The correct value is 675 instead of 693, the value of all configuration with at least rot2 symmetry.

Near misses with at least orthogonal reflection symmetry

In April 2006 I counted the near-misses in symmetry class ort1, ort2 and full for even n ≤ 26, n ≤ 46 and n ≤ 76, respectively, to get empirical evidence for the conjectures I, II and III (in conjecture III replacing 5 by 6). I.e., in these three symmetry classes I was looking for the maximal number of points which can be placed/chosen on/in the grid of given size n but which is less(!) than 2n. This means I defined a near-solution if 2n-2(ort1), 2n-4(ort2) or 2n-4(full) points can be placed on the grid. The results/counts of my research (computed on an Athlon MP 2000+ 1.6 GHz) are listed in this table.
Interpretation of the counts: For symmetry class full it seems the number of maximal points which can be placed are drifting further and further away from 2n with increasing n. For symmetry class ort2 this drifting away trend is much weaker, but if the maximal achieving points is 2n-2 then the number of these near-solutions is decreasing with increasing n. For symmetry class ort1 I do not recognize a clear trend in these few data.
Therefore I think for the two symmetry classes ort2 and full, these numbers give (very) strong evidence that no more solutions for the no-three-in-line problem exist for n > 46 and thus conjectures I and II might be true.
BTW: Conjecture III is false (known since June 1996), but whether it would be true if replacing 5 by a small number >= 7, this is an open question.

Minimal defect for fixed symmetry and grid size

The defect is defined as the difference of the maximal achievable number of selectable points in the nxn grid to 2n. In April 2026 I computed the minimal defect of no-three-in-line configuration for small grid sizes n and fixed symmetry-classes. Moreover I counted the number of non-equivalent configurations (regarding the chosen symmetry group) which achieves this defect. Thus these are algorithm-independent values for those near-misses in the previous paragraph.
