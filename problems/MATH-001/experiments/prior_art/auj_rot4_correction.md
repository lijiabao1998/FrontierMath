# rot4 多重图模型纠错与局部亏空屏障

## 1. 最重要的纠错

旧的 `build_general_model` 对每个无序端点对 \(u<v\) 加了

\[
x_{uv}+x_{vu}\le1.
\]

这条约束是错的。基本单元 \((u,v)\) 与 \((v,u)\) 是两个不同的 C4
轨道；在缩约的 2-正则对象中，它们是同一端点对之间的两条平行边，
可以组成二圈。原研究目录对小 \(m\) 的全解普查也明确记录了 digon
（平行边）实际存在。

`verify_rot4_antiparallel_pair_model.py` 已对全部
\(\binom{37}{2}=666\) 对做了独立点集穷举。每一对均满足：

- 两个 C4 轨道互不相交，共 8 个点；
- 占四行四列，每行每列恰好 2 点；
- 两轨道并集内部无三点共线。

输出 `rot4_antiparallel_pair_model_audit.json`，失败数为 0。

旧模型还有第二个相关错误：若旧方向 \((u,v)\) 被保留，它禁止再加入
反方向 \((v,u)\)。修正模型中：

- 原方向重新选择要求对应旧边先删除；正规化后可完全禁止这种冗余重选；
- 反方向可以在旧方向保留时加入，形成合法平行边；
- “实际翻转”只在反方向被选且对应旧边确实被删除时计数。

`--forbid-antiparallel` 现只作为复现旧结果的 legacy 开关，完整模型默认
允许两方向并存。

## 3. 新的 q=0 局部亏空判据

固定删除掩码 \(R\) 后，每个缩约顶点的亏空

\[
d_R(v)\in\{0,1,2\}.
\]

候选有向单元先用 blocker oracle 相对“保留的旧点集”做精确单轨道
过滤。此时 q=0 影子问题是一个允许环和平行边的亏空 \(f\)-factor：

- \(d(v)=1\)：必须选一条安全非环边；
- \(d(v)=2\)：必须选一个安全环，或两条不同的安全非环有向边；
- 两条反向有向边可以同时选择，恰好形成 digon。

专用 C++ DFS 每步选一个正亏空顶点，并一次填满它的全部剩余亏空。
这一步对 \(d=1,2\) 的上述选择逐一穷尽。选完后该顶点亏空归零，
所以已用边不可能在后续再次被选；因此只用剩余亏空向量作 memo key
也是完备的。

这个 DFS 不是启发式：它精确决定固定删除掩码是否有 q=0 多重图
\(f\)-factor。若 q=0 已不可行，则无需检查任意新轨道之间的冲突或
任何短方向容量，真实 NTIL 修复当然也不可能。

更强的经验结构是：绝大多数缺陷命中掩码在 DFS 根节点就失败。也就是
存在一个正亏空顶点：

- 亏空 1 却没有任何安全邻边；或
- 亏空 2 却既无安全环，也无法找到两条可同时使用的安全邻边。

这可称为“局部星容量证书”，比一般 Tutte 障碍更简单。

## 8. 方法上的重磅变化

此前单体 CP-SAT 同时选择删除掩码与替换 \(f\)-factor，q=0 也会在
300 秒后保持 UNKNOWN，累计超过百万分支。分层后：

1. 用循环段结构精确枚举删除掩码；
2. 先检查缺陷命中；
3. 对固定掩码运行至多 18 个活跃顶点的专用 \(f\)-factor DFS；
4. 只对百万分之一量级的 q=0 例外加入 q=1 CP-SAT。

这样把一个 300 秒无结论的问题变成“数亿形状的全覆盖 + 数十个毫秒级
例外证书”。真正的理论突破不是增加算力，而是找到正确的分解层次：

\[
\text{删除段/圈分支}
\;\to\;
\text{局部星容量}
\;\to\;
\text{精确多重图 }f\text{-factor}
\;\to\;
\text{q=1 高斯资源}.
\]

独立交叉核验还包括：666 对反向平行轨道的直接几何穷举、50 个
k=5…11 C++ 负样本与两个正样本的 CP-SAT 复算，以及 20 个 k=12
C++ 负样本和四个全删除正控制。全部一致。
